Abstract
This paper proposes a new approach to solving high-dimensional dynamic programming (HDDP) problems in economics by leveraging the Set Transformer architecture
introduced by Lee et al. [2019]. Traditional dynamic programming methods often face
challenges due to the curse of dimensionality, and existing neural network architectures, such as Deep Sets, struggle to capture complex, nonlinear interactions in highdimensional data. The Set Transformer, with its advanced attention mechanisms and
induced set attention blocks, overcomes these limitations by efficiently approximating
permutation-invariant functions, making it particularly well-suited for heterogeneous
agent models. Using a methodology based on minimizing Euler residuals, this study
ensures that the model adheres to economic theory while achieving superior accuracy and scalability. Comparisons with Deep Sets across varying model complexities,
including scenarios with linear-quadratic benchmarks and more nonlinear settings,
demonstrate the Set Transformer’s significant advantages. These results underscore
its potential to advance computational economics by providing robust and efficient
tools for analyzing complex economic dynamics.
Keywords: High-Dimensional Dynamic Programming (HDDP), Heterogeneous Agent
Models, Neural Networks, Set Transformer, Permutation Invariance

Introduction

Dynamic programming is a fundamental tool in economics, essential for solving sequential decision-making problems where outcomes depend on past and present decisions.
However, as the number of state variables increases, traditional dynamic programming
methods face the "curse of dimensionality," making computation infeasible. This issue
becomes particularly severe in heterogeneous agent models, which have become central
to modern macroeconomic analysis. These models, used to study distributions of wealth,
firm dynamics, productivity, and more, inherently involve high-dimensional state spaces
due to the presence of many interacting agents. As a result, solving them requires computational methods that can scale with dimensionality. Recent advancements in deep
learning, such as the deep set architecture introduced by Zaheer et al. [2017], have provided new avenues for approximating solutions in these high-dimensional settings.
The increasing complexity of economic models, particularly those involving highdimensional state spaces, has rendered traditional dynamic programming methods impractical. Although the deep set architecture offers some relief by leveraging permutation
invariance, it often struggles to accurately model the intricate dependencies and interactions among multiple state variables in these complex environments. This limitation can
be overcome by the "Set Transformer" architecture introduced by Lee et al. [2019], which
extends the capabilities of Deep Sets by incorporating attention mechanisms. These mechanisms allow the model to capture higher-order interactions among elements in a set,
making it well-suited for high-dimensional economic problems where agent heterogeneity and interaction structures are critical.
The primary objective of this study is to develop a new approach for solving highdimensional dynamic programming problems that frequently arise in heterogeneous agent
models. Building on recent advances in deep learning and set-based architectures, this
study introduces a Set Transformer-based model specifically tailored to these problems.
The model is evaluated against existing methods in terms of accuracy, scalability, and
1

computational efficiency, and its effectiveness is demonstrated across a range of economic
environments.
The Set Transformer is fundamentally built upon attention mechanisms, a powerful
innovation in machine learning. Attention mechanisms allow neural networks to dynamically focus on different parts of the input data, making them particularly effective at
capturing relationships between elements in complex datasets. In traditional sequencebased models, attention mechanisms enable the model to prioritize certain parts of the
sequence based on their relevance to the task at hand.
Expanding on the capabilities of attention mechanisms, the Set Transformer is specifically designed to handle sets of data, where the order of elements is irrelevant. This
permutation-invariant architecture is particularly well suited for heterogeneous agent
models, where agents are indistinguishable apart from their state variables, and the aggregate outcome depends on the distribution, not the ordering, of individual agents. In
such settings, accurately modeling the interactions among agents requires methods that
respect this invariance. By leveraging attention mechanisms, the Set Transformer can capture complex dependencies between elements in a set, offering a more robust and flexible
approach to solving high-dimensional dynamic programming problems than previous
architectures like Deep Sets.
The model in this study is a permutation-invariant heterogeneous agent model, adapted
from the Lucas Jr and Prescott [1971] model of investment under uncertainty, involving multiple firms. Kahou et al. [2021] utilized the Deep Sets architecture to solve this
model, which serves as an ideal test case for several reasons. In the special case of a
linear demand function, the model aligns with a well-known linear-quadratic (LQ) solution, as presented by Ljungqvist and Sargent [2018] to illustrate recursive competitive
equilibria. This provides an exact benchmark to validate our methods. Additionally,
the model is straightforward enough to offer clarity while being rich enough to capture
high-dimensional dynamic programming’s core features. Moreover, by adjusting certain

The contribution of this study is to introduce a Set Transformer-based solution to highdimensional dynamic programming problems in economics, addressing several key limitations of existing deep learning approaches. While deep learning is a relatively new and
evolving tool for such problems, current methods often lack scalability, suffer from interpretability issues, and may not generalize well across different economic models. The Set
Transformer architecture, with its attention-based design, provides a more robust and efficient alternative by better capturing complex interactions within high-dimensional and
permutation-invariant economic settings.
One of the key motivations for this research is the need for more efficient and accurate computational methods in economic modeling. This study addresses longstanding computational challenges in dynamic programming problems with high-dimensional
state spaces, particularly those arising in heterogeneous agent models. It proposes a solution based on the Set Transformer architecture, demonstrating how attention mechanisms

method achieves substantial improvements in both accuracy and scalability compared to

beyond. In doing so, this work not only overcomes key limitations of current approaches

Literature Review

The challenge of solving high-dimensional dynamic programming (HDDP) problems has
been a focal point in economic research, primarily due to the computational difficulties
imposed by the curse of dimensionality. Traditional methods, such as the Krusell-Smith
(KS) approach (Krusell and Smith [1998]), have been instrumental in addressing these
challenges by approximating the distribution of states using a small number of moments.
However, as noted by Krusell and Smith [1998], this method is limited in its ability
to handle models with multiple shocks and endogenous states, particularly when nonlinearities are involved (Den Haan [2010]).
To overcome these limitations, alternative approaches such as local perturbation techniques have been developed. Schmitt-Grohé and Uribe [2004] and Reiter [2009] contributed significantly to this field by expanding policy functions around a deterministic steady state. While effective for small stochastic deviations, these methods are less
reliable in scenarios where aggregate shocks induce significant non-linear or non-local effects, such as those encountered in macro-finance models with zero lower bounds (ZLB)
or large aggregate shocks (Boppart et al. [2018]; Bayer and Luetticke [2020]).
The advent of deep learning has opened new avenues for overcoming the curse of
dimensionality in HDDP problems. Rust [1997] pioneered the use of computational techniques to solve dynamic discrete choice models, laying the groundwork for integrating
machine learning into dynamic programming. Zaheer et al. [2017] introduced the "Deep

4

Sets" architecture, which is particularly useful for models involving heterogeneous agents
due to its ability to handle permutation invariance. However, while Deep Sets provided
a significant advancement, they often fall short in capturing the full complexity of interactions within high-dimensional data, necessitating more advanced architectures.
In this context, Han et al. [2021] developed DeepHAM, a deep learning-based method
that uses generalized moments to efficiently represent state distributions in HDDP problems. DeepHAM’s use of permutation-invariant generalized moments improves interpretability and computational efficiency by directly simulating paths rather than optimizing over an objective function that includes the Bellman residual. This approach contrasts
with other deep learning methods, such as those by Maliar et al. [2021] and Azinovic et al.
[2022], which also use deep learning to solve HA models with aggregate shocks but do
not address permutation invariance as effectively. DeepHAM has demonstrated superior
global accuracy and efficiency, reducing Bellman equation errors significantly compared
to traditional methods like KS.
Moreover, DeepHAM offers a novel solution to the constrained efficiency problem
in HA models, a challenge that has not been adequately addressed by previous methods. The ability to solve the constrained efficiency problem as quickly as the competitive
equilibrium makes DeepHAM a powerful tool for studying optimal fiscal and monetary
policies in models with aggregate shocks. However, the implementation of such models is complex, and the need for extensive computational resources remains a significant
concern (Han et al. [2021]).
In parallel, Kahou et al. [2021] advanced the literature by proposing a method that
exploits symmetry in the law of motion and the value function in HDDP problems. Their
approach leverages the concentration of measure and advanced deep learning techniques
to efficiently calculate high-dimensional expectations using a single Monte Carlo draw.
This method significantly reduces the computational complexity traditionally associated
with these problems, allowing for the global solution of a multi-firm investment model

5

under uncertainty-a scenario where traditional methods like the KS approach or local
perturbations would struggle. Kahou et al. [2021]’s work also builds upon foundational
techniques in the field, including the adaptive sparse grid method of Krueger and Kubler
[2004] and the value function iteration on grids developed by Judd et al. [2017].
While the "Deep Sets" architecture introduced by Zaheer et al. [2017] marked a significant improvement in handling permutation invariance in models with heterogeneous
agents, it has limitations in capturing complex and high-order interactions within highdimensional data. To address these limitations, the "Set Transformer" architecture was
proposed by Lee et al. [2019]. The "Set Transformer" builds upon the foundation laid by
"Deep Sets" by incorporating self-attention mechanisms, which allow for more nuanced
and flexible modeling of relationships within a set.
Attention mechanisms have become a cornerstone in modern machine learning models, particularly those dealing with complex data structures. The concept was first introduced by Bahdanau et al. [2014] to improve the performance of neural machine translation models. By allowing the model to selectively concentrate on relevant parts of the
input sequence, attention mechanisms significantly enhanced the ability of neural networks to capture dependencies across different parts of the data.
The pivotal moment in the evolution of attention mechanisms came with the introduction of the Transformer model by Vaswani [2017]. This model utilized self-attention
mechanisms, enabling each element in a sequence to attend to all other elements simultaneously, thus eliminating the need for recurrent layers. The self-attention mechanism
proved to be particularly effective in processing sequential data more efficiently and accurately, setting a new standard in natural language processing and beyond.
Building on the principles established by these earlier works, Lee et al. [2019] extended the concept of attention from sequences to sets with the Set Transformer. Unlike
traditional models that process data in a specific order, the Set Transformer applies selfattention mechanisms in a permutation-invariant manner. This means that the order of

6

elements in the input set does not affect the output, making the Set Transformer uniquely
suited for tasks where the order of inputs is irrelevant but their relationships are critical.
This architecture has demonstrated significant potential in economic modeling, particularly in approximating policy functions where the interactions among variables need to
be accurately captured regardless of their arrangement.
Unlike Deep Sets, which use a simple pooling function to aggregate information, the
"Set Transformer" leverages attention layers to dynamically weigh the importance of different elements within a set. This attention-based approach allows the Set Transformer
to capture higher-order interactions, making it particularly well-suited for complex economic models where the relationships between agents or variables are not merely additive but involve intricate dependencies. By processing the model’s inputs in a permutationinvariant manner, the Set Transformer can effectively model the interactions among multiple state variables, regardless of their order. This flexibility and power have been shown
to significantly improve both the accuracy and scalability of solutions to high-dimensional
dynamic programming problems, offering a robust framework for such models. As a result, the Set Transformer presents a promising direction for future research in dynamic
programming and economic modeling, providing a more precise and efficient alternative
to traditional methods.
Recent studies highlight the Set Transformer’s effectiveness beyond economics, particularly in applied mathematics and quantitative finance, such as option pricing. Aghapour
et al. [2025] employed the Set Transformer architecture to solve a permutation-invariant
partial differential equation (PDE), noting its suitability for problems in which payoff
functions exhibit permutation invariance. In option pricing, where most payoff functions
are permutation-invariant, the Set Transformer demonstrated strong performance, providing accurate solutions efficiently. This application underscores the versatility of the
Set Transformer in handling permutation-invariant structures across diverse quantitative
fields.

7

The transversality condition plays a critical role in dynamic programming models by
ensuring that solutions are economically meaningful and stable over time. Traditional numerical methods often require explicit enforcement of this condition to prevent explosive
trajectories and guarantee convergence. However, recent advancements in deep learning have shown that neural networks can implicitly satisfy the transversality condition
without explicitly imposing it. Kahou et al. [2021] demonstrated that over-parameterized
neural networks trained with stochastic gradient descent (SGD) naturally converge to solutions that respect boundary behavior, driven by the regularization effects of SGD. Similarly, Kahou et al. [2022] highlighted that deep learning approximations inherently satisfy
long-run boundary conditions, such as the transversality condition. They attributed this
to the implicit bias of deep learning toward functions with small derivatives, which aligns
with the class of solutions needed in dynamic models. These findings underscore the suitability of deep learning frameworks for solving high-dimensional dynamic programming
problems without explicitly solving for boundary conditions at infinity.

Computational Methodology

In this section, we present the quantitative methodology used to solve the high dimensional dynamic programming problem within our heterogeneous agent model. Our approach leverages the Set Transformer architecture, chosen for its capacity to handle permutation invariant structures, making it well-suited for our economic setting where the
ordering of agents does not affect outcomes.
Kahou et al. [2021] applied the Deep Sets architecture to solve the same model we
consider in this study. Deep Sets provided a foundational approach for handling permutation invariance, capturing symmetric relationships among agents. However, the Set
11

Transformer extends this framework by using attention mechanisms to model complex,
higher-order dependencies among elements in the input set. This allows it to capture
interactions that depend not just on individual agent characteristics, but also on their
joint configurations and mutual influences, a feature particularly relevant in economic
environments with strategic or aggregate effects. Building on this, we propose a new
method that applies the Set Transformer architecture to high-dimensional dynamic programming problems in heterogeneous agent models, aiming to improve both accuracy
and scalability. For readers unfamiliar with neural networks, we provide an overview in
Appendix A, and we introduce the Deep Sets architecture with its mathematical formulation in Appendix B.
The core of our method involves approximating the policy function u( x, X ) by training
the Set Transformer to minimize Euler residuals. Specifically, the Euler equation, derived
from the model’s first-order conditions, provides a necessary condition for optimality. By
minimizing these residuals across a comprehensive range of state variables, we ensure
that the approximated functions adhere closely to economic theory while maintaining
computational efficiency and scalability. We also note that the transversality condition is
not imposed explicitly but is implicitly satisfied through the training process, as discussed
in Appendix C.
The subsections that follow outline the key components of this process. We begin
with an overview of the Set Transformer architecture and its features that make it suitable
for permutation-invariant data. Next, we discuss neural network training process and
sampling techniques for preparing the state variables used in training.

4.1

Set Transformer Architecture

The Set Transformer is a neural network architecture specifically designed for processing
sets of data, where the order of the elements in the set does not matter. This permutation invariance property makes the Set Transformer particularly suitable for tasks in
12

economics, such as approximating policy and value functions in dynamic programming,
where the order of inputs (e.g., state variables) should not influence the outcome.
The core idea behind the Set Transformer is to ensure that the output of the model is
invariant to the permutation of the input set. Formally, if X = { x1 , x2 , . . . , xn } is a set,
then for any permutation π of the indices, the Set Transformer should satisfy

SetTransformer({ xπ (1) , xπ (2) , . . . , xπ (n) }) = SetTransformer({ x1 , x2 , . . . , xn })

(7)

This is achieved through the use of self-attention mechanisms that operate over the
entire set, treating each element symmetrically and ensuring that the output respects this
permutation invariance.
Consider a set of n query vectors, each with a dimension dq , represented by Q ∈ Rn×dq .
An attention function, denoted Att( Q, K, V; ω ), maps these queries Q to outputs using
nv key-value pairs, where K ∈ Rnv ×dq and V ∈ Rnv ×dv :

In this setup, Multihead( X, Y, Y; ω ) computes multi-head self-attention among elements in X and Y, with each attention head adjusted by the function ω. Layer normalization (see Ba et al. [2016]), represented as LayerNorm, and a row-wise feedforward layer,

SAB( X ) = MAB( X, X ).

(13)

By stacking multiple SABs, higher-order interactions between set elements can be encoded effectively. However, the SAB has a time complexity of O(n2 ), which can make it
computationally expensive for large sets as it requires calculating pairwise interactions
14

for all elements (Lee et al. [2019]).
The Induced Set Attention Block (ISAB) is designed to address this computational limitation by introducing a set of m learnable vectors known as inducing points, which serve
as intermediaries that reduce the computational load. Given an input set X ∈ Rn×d and a
set of inducing points I ∈ Rm×d , the ISAB first computes an intermediate representation
H by applying attention from the inducing points I to the input set X:

H = MAB( I, X ).

(14)

Next, it computes attention from X to H:

ISABm ( X ) = MAB( X, H ).

(15)

This two-stage process allows the inducing points to act as a lower-dimensional projection of the input set, capturing its global features and making it more efficient to process, especially with larger sets. This design reduces the time complexity to O(nm), where
m is typically much smaller than n, making ISAB suitable for larger input sets without
sacrificing the model’s ability to capture complex dependencies.
Both SAB and ISAB are permutation equivariant, meaning their outputs remain consistent regardless of the order of elements in the input set, which is a key property for set
data, where the order of elements should not affect the model’s output (Lee et al. [2019]).

4.2

Justification for Using Set Transformer

In the context of solving high-dimensional dynamic programming problems, the Set Transformer can be used to approximate permutation-invariant functions, such as the policy
18

function u( x, X) or the value function v( x, X). The permutation invariance ensures that
the model respects the symmetry in the input data, where the order of elements in the set
(e.g., different firms in an economy) should not affect the output.
The choice of the Set Transformer architecture in this research is driven by its unique
ability to address the limitations inherent in previous architectures, such as Deep Sets,
particularly when applied to high-dimensional dynamic programming problems.
One of the primary limitations of Deep Sets is their reliance on simple pooling operations to aggregate information across input elements. While this approach ensures permutation invariance, it restricts the network’s ability to capture complex, non-additive
interactions among agents. In many economic models, especially those involving heterogeneous firms or agents, individual decisions depend not only on the aggregate state but
also on the configuration of the distribution itself. For example, a firm’s optimal investment decision may be influenced by the relative positions of its competitors in the state
space, not just the average or total capital. The Set Transformer addresses this by using attention mechanisms that allow each element to interact with others directly, enabling the
network to learn richer, context-dependent representations. This leads to more accurate
approximations of the policy and value functions in environments where distributional
detail and agent-level interactions are economically meaningful.
The Set Transformer addresses these limitations through its use of attention mechanisms, which dynamically weigh the importance of different elements in the set based
on their relevance to the task at hand. Unlike Deep Sets, the Set Transformer does not
rely solely on a pooling function but instead uses self-attention to capture intricate relationships within the data. This allows the model to represent more complex interactions
between the elements of a set, which is particularly valuable in high-dimensional settings
where the relationships between variables are not merely additive but involve complex
dependencies.
Moreover, the Set Transformer incorporates the Induced Set Attention Block (ISAB),

19

which further enhances its ability to manage large sets efficiently. By introducing a set
of inducing points, the ISAB reduces the computational complexity associated with selfattention while preserving the model’s capacity to capture detailed interactions. This
innovation is particularly important for solving high-dimensional dynamic programming
problems, where the state space can be vast, and computational efficiency is crucial.
Further supporting the choice of the Set Transformer, Lee et al. [2019] have demonstrated its superiority over Deep Sets in approximating critical permutation-invariant
functions, such as the minimum, maximum, and clustering functions. These functions are
fundamental in various tasks where capturing the nuanced relationships within a set is
crucial. In the context of our economic model, where the goal is to find the nonlinear relationships between the decisions of different firms, the Set Transformer’s ability to handle
such complexities makes it a more powerful tool compared to simpler architectures like
Deep Sets. By leveraging the advanced attention mechanisms of the Set Transformer, this
research anticipates achieving more accurate and robust approximations of the policy and
value functions, thereby offering a significant improvement in solving high-dimensional
dynamic programming problems.

Conclusion

In this paper, we proposed a computational solution method for high-dimensional dynamic programming (HDDP) problems using the Set Transformer architecture. By leveraging the attention mechanisms and permutation invariance of the Set Transformer, we
addressed the limitations of previously used architectures, such as Deep Sets, in capturing complex dependencies in heterogeneous agent models. Our work extends previous
research by providing a thorough comparison of these architectures under varying economic scenarios, including both linear-quadratic (LQ) cases and more complex, nonlinear
settings.
We demonstrated that the Set Transformer significantly outperforms Deep Sets in
terms of policy error and mean squared error (MSE), particularly as the model complexity
increases. For ν = 1, where an LQ benchmark solution is available, the Set Transformer
achieved errors nearly 100 times lower than Deep Sets, confirming its superior accuracy
and efficiency. For larger values of ν, where the inverse demand function becomes more
nonlinear and no LQ solution exists, the Set Transformer continued to exhibit strong performance, maintaining its advantage over Deep Sets even as both architectures experienced performance degradation.
Additionally, we have argued that the deep learning’s tendency to the minimum norm
solutions leads to satisfy the transversality condition without explicit enforcement. This
property, as supported by prior studies such as Kahou et al. [2021, 2022], arises from the
inherent regularization effects of stochastic gradient descent and the implicit bias of deep
learning architectures toward smooth, stable solutions.
This study highlights the potential of attention-based architectures like the Set Transformer in solving high-dimensional dynamic programming problems with complex economic interactions. Its ability to generalize across different economic environments and
handle nonlinearities makes it a promising tool for future applications in computational
economics. In particular, it enables the solution of richer models with detailed hetero28

geneity and more realistic market structures, without requiring simplifications that are
often necessary in traditional approaches. This expands the frontier of feasible quantitative analysis, especially in settings where agent-level interactions and high-dimensional
state spaces play a central role.

Deep Sets Architecture

The Deep Sets architecture, introduced by Zaheer et al. [2017], provides a foundational
approach to handling permutation-invariant data by ensuring that the order of elements
within a set does not affect the model’s output. This characteristic makes Deep Sets suitable for scenarios where the relationships among elements are symmetric, as in many
economic and multi-agent models.
The key idea of Deep Sets is to model a permutation-invariant function f : Rn → R
35

by decomposing it into two main components. Mathematically, this can be represented
as


f (X) = ρ pool ϕ( x1 ), ϕ( x2 ), . . . , ϕ( xn ) ,

where X = { x1 , x2 , . . . , xn } is the input set of elements, ϕ : R → Rd is a transformation
function that maps each element xi individually to a higher-dimensional space, pool(.)

and ρ : Rd → R is another function that processes the aggregated output to produce the
final prediction.
In this structure, the transformation ϕ captures information about each element independently, while the aggregation function (summation or mean) combines these individual representations in a way that is invariant to the order of the elements in the input set.
Finally, ρ maps the aggregated result to the desired output.

This decomposition is powerful but limited in capturing complex, higher-order interactions among elements of the set. Deep Sets can handle simple dependencies but struggle with more intricate relationships, where interactions between elements are essential.
For example, Deep Sets fail to efficiently approximate the maximum function, which is a
permutation-invariant function (Lee et al. [2019]) . This limitation is addressed in the Set
Transformer architecture, which extends Deep Sets by incorporating self-attention mechanisms to capture more complex dependencies within the set.
In practice, we typically use feed-forward neural networks to implement the functions
ϕ and ρ in Deep Sets. These neural networks are flexible and capable of capturing complex relationships within the data. By training these networks to minimize the error of the

parameters of these neural networks are adjusted through backpropagation, allowing the
model to learn how each element in the set contributes to the aggregated result and final
output.

On Implicit Satisfaction of the Transversality Condition

A well-known requirement in solving dynamic programming problems is the transversality condition, which ensures the long-term stability and feasibility of the solution. In
deep learning-based approaches, this condition is typically not imposed explicitly. Kahou
et al. [2021] argue that deep neural networks tend to satisfy the transversality condition
implicitly through the training process.
Specifically, the use of stochastic gradient descent (SGD) introduces an implicit regularization effect. Through iterative updates on minibatches of data, SGD encourages
convergence to solutions that generalize well and exhibit stable behavior over time. This
effect is especially pronounced in over-parameterized networks, which tend to converge
to minimum-norm solutions that avoid explosive trajectories.
Kahou et al. [2021] observe that this behavior allows deep learning models to comply
with the transversality condition without requiring explicit boundary constraints. They
also find that the learned solutions often align with ergodic distributions, indicating stable long-term dynamics. Similarly, Kahou et al. [2022] demonstrate that deep learning
approximations inherently satisfy long-run conditions, including the transversality condition, even in models with steady-state multiplicity. This arises from deep learning’s
bias toward functions with small derivatives, which match the class of solutions typically
expected in dynamic models. These findings suggest that deep learning methods are well
suited for approximating transition dynamics in high-dimensional state spaces without

37

explicitly solving boundary conditions at infinity.
